# herbloom-backend

Backend for the HerBloom women's health platform.

## Scripts

| Command       | Description              |
| ------------- | ------------------------ |
| `npm run dev` | Start with nodemon       |
| `npm start`   | Start production server  |
| `npm test`    | Run tests (add your suite)|
| `npm run lint`| Lint code                |
| `npm run format` | Format code          |

## Environment

Copy `.env.example` to `.env` and fill in your values. See `.env.example` for all required keys.
